RAV PRAISE TEAM — PAQUETE COMPLETO PARA EL REPOSITORIO

1. Descarga y extrae este ZIP.
2. Sube TODO su contenido a la carpeta de tu repositorio donde está index.html.
   Reemplaza index.html, manifest.webmanifest, sw.js y logo.png.
   Incluye la carpeta icons completa. No subas solamente el ZIP.
3. Espera a que GitHub Pages termine de publicar y abre tu sitio con HTTPS.
4. Actualiza la página y vuelve a abrir la app si ya la tenías instalada.

INSTALAR
iPhone / iPad: abre el sitio en Safari y usa Compartir > Agregar a inicio.
Android: abre el sitio en Chrome y usa Instalar app / Agregar a pantalla de inicio.
